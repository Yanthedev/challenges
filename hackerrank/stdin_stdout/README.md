## Desafio: Entrada e Saída de Dados

Neste desafio, o objetivo é praticar a leitura de dados pelo terminal utilizando Java.

O programa deve receber **três números inteiros**, cada um em uma linha diferente, e exibi-los exatamente na mesma ordem, imprimindo um valor por linha.

### Exemplo de Entrada

```text
42
100
125
```

### Exemplo de Saída

```text
42
100
125
```

### Conceitos praticados

* Leitura de dados com `Scanner`
* Entrada padrão (`stdin`)
* Saída padrão (`stdout`)
* Manipulação de números inteiros em Java
