# Challenges

Repositório destinado ao armazenamento de desafios práticos de programação e estudos relacionados ao desenvolvimento de software.

## Objetivo

Este repositório tem como finalidade:

- praticar lógica de programação;
- consolidar fundamentos da linguagem Python;
- exercitar resolução de problemas;
- desenvolver boas práticas de estruturação de código;
- acompanhar evolução técnica ao longo dos estudos.

---

## Tecnologias Utilizadas

- Python
- Git
- GitHub
- SQL
- Pandas
- Numpy
