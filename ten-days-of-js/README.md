👨🏼‍💻 Ten Days of JavaScript

Bem-vindo ao meu repositório do desafio 10 Days of JavaScript, da HackerRank.

Aqui estou registrando minha jornada de aprendizado em JavaScript através da resolução dos desafios propostos pela plataforma. Mais do que simplesmente encontrar respostas, meu objetivo é desenvolver raciocínio lógico, fortalecer minha base na linguagem e aprender a resolver problemas de forma estruturada.

Acredito que programar vai muito além de decorar sintaxe. Antes de escrever qualquer linha de código, procuro entender o problema, analisar possíveis soluções e construir uma lógica clara para então transformá-la em código.

🥋 Sobre o desafio

O 10 Days of JavaScript é uma trilha de estudos da HackerRank composta por desafios progressivos que abordam conceitos fundamentais da linguagem.

Durante os exercícios são explorados temas como:

Variáveis e tipos de dados
Operadores
Funções
Loops
Arrays
Objetos
Classes
Expressões regulares
Tratamento de erros
Boas práticas de programação
📂 Organização

Cada pasta representa um dia do desafio.

Dentro de cada diretório você encontrará:

A solução do desafio
Comentários explicando a implementação
Anotações importantes quando necessário

O objetivo é manter um histórico organizado da minha evolução durante o desafio.

🎯 Objetivos

Com este repositório pretendo:

Consolidar meus conhecimentos em JavaScript;
Melhorar minha lógica de programação;
Desenvolver habilidades de resolução de problemas;
Criar o hábito de documentar meus estudos;
Construir um portfólio que represente minha evolução como desenvolvedor.
