# Manipulação de Strings em Python

Este conjunto de exercícios tem como objetivo praticar os principais recursos de manipulação de strings em Python. O foco está no tratamento, validação, extração e formatação de textos, habilidades fundamentais para quem está estudando programação, análise de dados e ciência de dados.

No primeiro exercício - "string-transformation", são trabalhadas transformações básicas de texto, como remoção de espaços nas extremidades, conversão para letras maiúsculas, conversão para letras minúsculas e capitalização da primeira letra. Essas operações são muito utilizadas no tratamento de dados textuais inseridos por usuários ou extraídos de bases de dados.

No segundo exercício - "email-validator", o objetivo é criar um validador simples de e-mail. Para isso, são verificadas condições como a existência do caractere `@`, a terminação do endereço com `.com` ou `.com.br` e a ausência de espaços. Esse exercício reforça o uso de operadores de pertencimento e métodos de verificação de strings.

No terceiro exercício - "string-information-extractor", é praticado o fatiamento de strings a partir de uma data no formato `AAAA-MM-DD`. O programa deve extrair separadamente o ano, o mês e o dia, além de reorganizar essas informações no formato brasileiro `DD/MM/AAAA`.

No quarto exercício - "sales-report-fstrings", é desenvolvido um relatório de vendas utilizando f-strings. O objetivo é apresentar informações de forma organizada e profissional, aplicando formatação de moeda, porcentagem, casas decimais, separador de milhar e alinhamento de texto.

De forma geral, este tópico desenvolve habilidades importantes para lidar com dados textuais, validar entradas de usuário e criar saídas bem formatadas em Python.
