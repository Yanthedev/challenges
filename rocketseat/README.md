## 🎯 Objetivo

Esta pasta reúne desafios, exercícios e pequenos projetos desenvolvidos durante minha jornada de aprendizado em Java e Desenvolvimento Backend.

O principal objetivo é fortalecer minha lógica de programação, consolidar os fundamentos da linguagem Java e aprofundar conhecimentos em conceitos essenciais da Programação Orientada a Objetos (POO), estruturas de dados, algoritmos e boas práticas de desenvolvimento.

Além disso, este espaço serve como um registro da minha evolução técnica, permitindo acompanhar meu progresso por meio da resolução contínua de problemas e da implementação de soluções cada vez mais robustas.

Os desafios aqui presentes têm como foco o desenvolvimento das competências necessárias para atuar como Desenvolvedor Backend Java, incluindo raciocínio lógico, modelagem de soluções, escrita de código limpo e compreensão dos princípios fundamentais utilizados em aplicações profissionais.

🚀 Aprendendo, praticando e evoluindo um desafio de cada vez.
